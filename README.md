# Grimoire: Path of the Spellcaster

Мод для **Minecraft Forge 1.21.1**. Добавляет 3 руны (Огонь, Лёд, Молния) с
рабочей логикой заклинаний по правому клику и предмет-книгу "Гримуар"
(заготовка под будущий GUI комбинирования рун).

## Что уже работает

- **Руна Огня** — стреляет небольшим огненным шаром в направлении взгляда.
- **Руна Льда** — накладывает замедление на существ в радиусе 5 блоков.
- **Руна Молнии** — призывает молнию в ближайшего врага (или перед собой).
- **Гримуар** — предмет с описанием, точка расширения под GUI в будущем.
- Все предметы появляются в творческом инвентаре во вкладке "Гримуар: Магия".
- Локализация: русский и английский.

## Способ 1: собрать через GitHub Actions (проще всего)

1. Создай новый репозиторий на GitHub и залей туда всё содержимое этой папки
   (без изменений — workflow уже настроен).
2. Открой вкладку **Actions** в репозитории — сборка запустится автоматически
   при пуше в ветку `main` или `master`.
3. Когда сборка завершится (зелёная галочка), зайди в неё и скачай артефакт
   **grimoire-mod-jar** — внутри будет готовый `.jar` файл мода.

Это решает главную боль ручной сборки: не нужно возиться с
`gradle-wrapper.jar` (бинарный файл, который обычно идёт в комплекте с
официальным MDK Forge, но который я не могу сгенерировать здесь без доступа
к серверам Gradle). GitHub Actions сам ставит нужную версию Gradle.

## Способ 2: собрать локально

1. Установи **JDK 21** (например, Eclipse Temurin).
2. Установи **Gradle 8.8+** (https://gradle.org/install/), если его ещё нет.
3. В корне проекта выполни:
   ```
   gradle build
   ```
4. Готовый `.jar` появится в `build/libs/`.

> Если хочешь, чтобы `./gradlew` работал без установки Gradle вручную —
> после первого успешного `gradle build` выполни `gradle wrapper
> --gradle-version 8.8`, это создаст `gradlew`, `gradlew.bat` и
> `gradle-wrapper.jar`, которые можно закоммитить в репозиторий.

## Куда класть готовый jar

Скопируй файл из `build/libs/grimoire-1.0.0.jar` в папку `mods` твоей
Forge-версии Minecraft 1.21.1.

## Что можно добавить дальше

- **Мана** — новый ресурс через Forge Capability, который тратится на каст.
- **Комбинирование рун** — свой `Screen` + `AbstractContainerMenu` для
  Гримуара, где руны вставляются в слоты и дают составные заклинания.
- **Посох** — оружие, которое кастует заклинание, записанное в Гримуаре,
  без открытия книги.
- **Ритуалы** — блок "рунный камень", который активирует мощный эффект при
  правильной расстановке рун вокруг него.
- Замени текстуры-заглушки (`textures/item/*.png`, 16×16) на свои рисунки —
  структура и имена файлов менять не нужно.
